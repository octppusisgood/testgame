《回响之城》肉鸽模式 · 试玩版 —— 完整可编辑源码包
====================================================

一、这是什么
------------
本包是 Godot 游戏工程《回响之城》的完整源码（肉鸽模式试玩版）：
代码、场景、美术资源（Synty 等）、音效、配置、全部设计文档齐全，
可在任何电脑上用 Godot 打开、编辑、运行、导出。

二、环境要求（唯一依赖：Godot 编辑器）
------------------------------------
Godot 4.7.2（必须 4.7.x，低版本不兼容 .uid 文件与部分 API）
下载：https://godotengine.org/download/windows/
或命令行安装：winget install GodotEngine.GodotEngine
注意：选标准版（非 .NET 版）即可，本项目不用 C#。
本机参考路径（原开发机）：Godot_v4.7.2-stable_win64.exe

三、如何打开编辑
----------------
1. 解压本文件夹到任意位置（路径不要含全角引号等特殊字符）。
2. 打开 Godot → 右上角「导入」→ 选择本文件夹里的 project.godot → 打开。
3. 首次打开 Godot 会自动导入全部资源（进度条，约几分钟，只此一次）。
4. 按 F5 运行（主场景即主菜单）。

四、常用运行方式
----------------
· F5：正常开始（主菜单 → 单人/肉鸽）
· 测试模式（资源全满+调试键）：菜单选 5，或命令行：
  Godot_v4.7.2-stable_win64_console.exe --path . res://scenes3d/proto3d.tscn -- --test
· 启动游戏.bat / launcher.bat：本机快速启动菜单（里面 exe 路径按新电脑改）
· 游戏内调试键：F1 帮助 / F3 性能窗 / F12 调试信息；测试模式另有 F6-F11

五、肉鸽模式玩法循环（本试玩版主轴）
------------------------------------
系统空间（局外中枢：商城/基因库/强化仓/进入城市）
  → 进入城市（开局：WASD 移动，鼠标射击，X 建造，M 地图，J 随从面板，Q 远程炮击）
  → 关卡推进（能量场+守关 Boss，逐关递进，通关第 3 关即胜利）
  → 撤离（Esc 菜单「撤离本局」：非战斗按信号强度结算倍率）或阵亡（倍率减半）
  → 结算（材料×倍率折算 SP）→ 回系统空间 → 局外成长（SP 买属性/枪械强化/雇佣随从/弹药）
  → 下一局更强开局

七、自动化测试（改代码后建议跑）

基线 = 4 项失败（历史遗留，属正常；多 1 项即是你改出来的回归）。

八、导出成 exe（可选）
----------------------
工程含 export_presets.cfg。在 Godot 编辑器：
编辑 → 项目设置 → 导出，或 项目 → 导出，需先下载对应平台的导出模板
（编辑器内「管理导出模板」一键下载）。工具脚本 tools_export_slim.py
可做瘦身导出（配套 synty_exclude.txt）。
